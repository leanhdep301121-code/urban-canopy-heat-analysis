Urban canopy heat analysis repository draft

This folder is a local draft for a future code repository. It has not been uploaded to GitHub or assigned a DOI. No commercial temperature data are included.

The code/ folder preserves the author-supplied analysis, SVF, building metrics, road metrics and dataset-assembly scripts unchanged. source_manifest.json records file hashes, and import_inventory.json lists imported modules. The scripts currently include the original local input/output paths and are not yet a portable one-command reproduction package.

Before release, replace local paths with documented configuration; confirm which script version generated each manuscript result; archive the original environment/package versions; add a small permitted test dataset and exact reproduction commands; have the authors choose a code license and confirm publication of the processed datasets.

The manuscript uses 22 predictive inputs and the v20260820_BC_noFAR analysis branch. The original omnibus analysis source also contains unused/alternative models and exploratory branches. Those branches must not be mistaken for the manuscript's executed methods.

Data plan: put permitted figure source data and minimal processed datasets in a durable data repository such as Zenodo, and link the versioned data record from this code repository. Keep restricted commercial input data under the provider's access conditions. A GitHub code release may later be archived to obtain a DOI.

No LICENSE, repository address, DOI or claim of full reproducibility has been invented in this draft.
